# <최우수상- TFT LGBM 하이브리드 모델을 활용한 법정동 단위 119 신고 수요 예측>

## **1) 사용한 데이터와 주제 설명**

- **데이터**: 119신고 건수 자료, 기상관측 자료 (제공)
    - 외부 데이터 : 2020~2024년 월별 인구 데이터, 관내 행정 기관의 분포 데이터, 부산광역시 도로구간조서 및 지하차도, 터널 현황 데이터, 종합병원 현황 데이터, 해수욕장 방문 현황 데이터, 월별 코로나19확진자 및 사망자 발생현황 데이터, 소방재난본부 일반현황 데이터
- **주제**: 소방데이터와 날씨 빅데이터를 융합한 119 신고 건수 예측

## **2) 어떤 기법이 적용됐는지**

- **전처리**: 결측/중복 점검, 이상치 탐색
- 결측치 : RandomForest, ordinary krigging(크리깅)
- **모델 선정**: Temporal Fusion Transformer(TFT), LightGBM

## **3) 어떻게 문제에 접근했는지**

1. 외부데이터 수집 및 전처리
    1. 인구, 도시환경, 관광 및 휴양 → **법정동-행정도 매핑 작업** 수행
    2. 코로나19 : 2023년 9월 이후 집계 중단 후 기간은 결측값으로 처리
2. **EDA**로 일별 결측 현황, 기초 통계량 확인
    - 변수별 결측 현황 확인 및 변수간의 관계 확인
    - 연도별 일별 신고 건수를 시계열로 시각화하여 기초 통계 확인
3. 파생변수 생성
    1. 시간 변수 : 주말,공휴일 여부(이진 변수)+ 월,일을 주기로 sin,cos으로 변환한 변수
    2. 기상 변수 : 최고 습도와 최저 습도 차이를 이용한 습도차 변수
    3. 신고 종류 기반 파생변수 : 유사한 **신고 종류별로 grouping →** 예측정확도가 높은 분류 선정
4. **모델링**: TFT 기본, LightGBM로 잔차 보완 모델 생성
5. **결과 해석**: feautre importance 그래프를 그려서 모델에 영향을 미친 변수 확인

## **4) 분석 과정 코드 흐름 (EDA → 결측치 → 모델링)**

- **EDA**: 결측/중복 확인 → 분포
- **모델링**:
    - Temporal Fusion Transformer(TFT) 모델 : 다양한 변수 활용, 시계열 예측에 특화된 딥러닝 모델
        - 과거 7일 데이터를 기반으로 하루 단위 예측
        - 단위 지역 특성 임베딩
        - 시점별로 유의미한 변수만을 선택
        - 예측 시점에 영향을 주는 과거 구간 학습으로 장기 의존성 반영
    - LightGBM : TFT의 지역별 미세한 편차나 이상치에 대한 보정력 보완 모델로 선정
    - 최종 예측값 =  TFT 예측값 + LGBM 예측 잔차
- **해석/리포팅**: 모델에 영향을 미친 모델의 feature importance 그래프와 함께 해석 제공

## **5) 차별점 및 배울 점**

- 단순히 외부 데이터를 불러와서 파생변수를 만드는 것이 아니라 **파생변수간의 상호작용**을 생각하여 드러나지 않은 잠재적인 요소를 알아보고자 파생변수를 생성한 점
- 결측치를 대체하는 것에서 멈추지 않고, 데이터의 일부를 인위적으로 마스킹한 뒤 보간한 값과 실제 값을 비교하고 시각화를 하여 확인한 점
- **TFT 딥러닝 모델**을 사용한 이후에 TFT 모델의 한계점을 해소하기 위해서 LightGBM을 사용하여 잔차를 바탕으로 hybrid 보완 전략을 사용한 점

## 6) 모델 추가적인 공부

### Temporal Fusion Transformer(TFT)

![image.png](image.png)

1. **게이팅 메커니즘**(Gating Mechanisms)

- 모델 학습 시 과거 데이터 중 불필요한 시점의 입력을 통제하여 장기간 예측을 유리하게 함

2. **변수 선정 네트워크**(Variable Selection Networks)

- 각 time step마다 적절한 입력 변수 선정
- **Categorical Variables**에 대해서는 Entity Embedding을, **Continuous Variables**에 대해서는 Linear Transformation을 진행

3. **정적 공변량 인코더**(Static Covariate Encoders)

- 정적 공변량을 모델에 입력할 수 있는 형태로 통합하여 context vector로써 동적 변수의 조건으로 설정

4. **Temporal Processing**

- 관측 및 알고 있는 변수를 장단기 예측에 입력하기 위한 시점 처리, 해석 가능한 multi-head attention 기법 적용

5. **예측 시점 구간**(Prediction Intervals)

- **Prediction Intervals**을 통해 Quantile을 이용하여 매 Prediction Horizon에 대하여 Target이 존재할 수 있는 범위를 제공

# <우수상>

## **1) 사용한 데이터와 주제 설명**

- **데이터**: 119신고 건수 자료, 기상관측 자료 (제공)
- **주제**: 소방데이터와 날씨 빅데이터를 융합한 119 신고 건수 예측

## **2) 어떤 기법이 적용됐는지**

- **전처리**: 결측/중복 점검, 이상치 탐색
    - 날짜형 변수, 순서형 변수 : OrdinalEncoder 사용
    - 수치형 변수 : RobustScaler 사용
    - 범주형 변수 : One-Hot Encoder 사용→ 희소행렬화
- 결측치 : 선형보간법 적용 → 안되는 경우 추가적으로 중앙값으로 대치
- **모델 선정**: XGBoost Poisson 회귀 적용

## **3) 어떻게 문제에 접근했는지**

1. **EDA**로 결측치 확인, 변수들 간의 상관관계 확인 
2. 파생변수 생성
3. **모델링**: XGBoost Poisson 회귀

## **4) 분석 과정 코드 흐름 (EDA → 전처리→ 모델링)**

- **EDA**: 결측,확인 → 상관관계
- **모델링**: RandomizedSearchCV를 이용해서 하이퍼 파라미터 튜닝 → XGBoostRegressor 모델 이용
- **해석/리포팅**

## **5) 차별점 및 배울 점**

- 결측치를 처리할 때에 중앙값, 평균과 같은 기초 통계량이 아니라 선형보간법을 사용하여서 시간적 연속성을 무시하지 않은 점
- 각 변수들의 특성에 따라서 전처리를 진행한 점

## 6) 모델 추가적인 공부

### XGBoost의 **Poisson 회귀(Poisson Regression)**

- 특정 시간, 공간, 또는 노출(exposure) 범위 내에서 발생하는 이벤트의 횟수를 예측하는 데 사용되는 비선형 머신러닝 기법

`model = xgb.XGBRegressor(objective='count:poisson', n_estimators=100`

### 선형보간법

- 두 개의 알려진 값 사이에 위치한 어떤 지점의 값을 예측하는 방법
- 두 점을 직선으로 연결하고 그 직선 위의 특정 위치에서 값을 찾는 것
- 주로 시계열에서 간단하고 빠른 결측치 보완이 필요할 때 사용하는 것으로 알려짐.
